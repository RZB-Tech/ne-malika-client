# SEO: проверка и сопровождение

Технические изменения помогают обходу и пониманию сайта, но не гарантируют первое место.
Позиции зависят от запроса, конкуренции, качества предложений и доверия к сайту.

## После публикации

1. Подтвердить домен `nemalika.uz` в Google Search Console (DNS TXT — для всего домена).
   Для подтверждения через HTML использовать `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION`:
   добавить значение `content` как Repository Variable в GitHub и пересобрать Docker-образ.
2. Отправить `https://nemalika.uz/sitemap.xml` в Google Search Console и Яндекс.Вебмастер.
3. Проверить главную, `/category/laptops`, вложенную категорию и товар через URL Inspection
   и Google Rich Results Test. Проверять опубликованную версию, а не только локальную сборку.
4. Следить за Pages/Indexing, Crawl stats, Core Web Vitals и запросами в Performance.
   Сравнивать показы, клики и конверсии за сопоставимые периоды, а не обещать срок попадания в топ.

## Реализация

- Списки товаров и магазинов рендерятся сервером; пагинация доступна обычными ссылками.
  Порядок товаров изменён со случайного на новые первыми: страницы выдачи не перемешиваются
  между запросами посетителя и поискового робота.
- Каждая страница `?page=N` имеет свой canonical; поиск и альтернативная сортировка — noindex.
- Категории берутся из API. Вложенные адреса отражают иерархию; старые `?sub=id` перенаправляются.
- Sitemap содержит действующие корневые категории, товары и магазины из API.
  Вложенные категории доступны через `/category` и ссылки родителей.
  Сбой API не должен публиковать пустой sitemap с успешным статусом.
- Пустые категории временно noindex; при появлении товаров они снова доступны индексации.
- Разметка не придумывает бренд, MPN, гарантию и срок действия цены. Цена по договорённости
  не становится нулевой ценой. Отсутствие Offer у такой карточки допустимо, rich result не обещается.
- Фид Яндекса обходит все страницы товаров, использует реальные ID категорий и не придумывает
  доставку/самовывоз. Товары без заданной положительной цены не отправляются как ценовые предложения.
- Кабинеты и служебные разделы получают HTTP `X-Robots-Tag: noindex, nofollow`.
- Перевод интерфейса в localStorage — не отдельная языковая версия URL. Поэтому hreflang
  не добавлен: сначала нужны настоящие узбекские URL с переведённым серверным контентом.

## Контент

Добавлять точные модели, характеристики, качественные собственные фото и понятные описания;
поддерживать цены/наличие и данные магазинов; собирать только настоящие отзывы.
Полезные руководства по выбору техники должны отвечать на реальные вопросы покупателей,
а не дублировать ключевые слова. Накрутка отзывов, покупка спам-ссылок и скрытый текст не используются.

## Проверки

`node --test test/seo.test.mjs` — чистые SEO-функции и обработка сбоев API.

`SEO_TEST_BASE_URL=http://localhost:3012 node --test test/seo-http.test.mjs` — проверка
HTML запущенной production-сборки без исполнения JavaScript. По умолчанию HTTP-тесты пропускаются.

Документация: https://developers.google.com/search/docs/specialty/ecommerce/pagination-and-incremental-page-loading
